<p align="center">
  Телеграмм Бот для заявок в отдел ИТ
</p>


**Цель создания:** <br>
Автоматизация сбора заявок от пользователей. Учёт выполненных и не выполненных задач. Простота обращения в ИТ отдел, без совершения звонков.

**Механизм работы:**

Пользователь через бота в Телеграмм подаёт заявку, отвечая на вопросы, которые получает в процессе диалога. 
После нажатия кнопки "Отправить заявку" бот сообщает об успешной отправке заявки с её номером и содержимым.
Заявка поступает в группу участниками которой являются сотрудники ИТ отдела. 
Начальник ИТ отдела назначает ответственного за выполнение заявки. Может оставить комментарий.
После выполнения заявки, в группе для заявок сотрудник отмечает, что заявка выполнена.
Бот отправляет пользователю информацию о том что его заявка выполнена.

В случае если заявка не заполнена полностью и не отправлена через 30 минут бот информирует пользователя об этом и возвращает пользователя на начало заполнения заявки.
У начальника есть exel файл с номерами не выполненных заявок, данные в файле актуализируются в процессе поступления новых заявок и выполнении старых
С ботом может работать одновременно 2 пользователя и заполнять каждый свою заявку.
При необходимости к заявке можно прикрепить фотографии
Есть возможность через бота отправить информацию пользователю, например если заявку он подал некорректно, и для её выполнения требуется обратиться в другой отдел
