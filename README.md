  Телеграмм Бот для заявок в отдел ИТ
</p>


Цель создания:
Автоматизация сбора заявок от пользователей. Учёт выполненных и не выполненных задач. Простота обращения в ИТ отдел, без совершения звонков.

Механизм работы:

Пользователь через бота в Телеграмм подаёт заявку, отвечая на вопросы, которые бот задаёт в процессе диалога. Пользователь может прикрепить фотографию и нажав кнопку "Отправить заявку" отправляет заявку.
В ответ от бота получает сообщение об успешной отправке заявки с её номером и содержимым. 

Далее бот отправляет заявку в отдельно созданную группу. В этой группе находятся сотрудники ИТ отдела. 

Начальник ИТ отдела назначает ответственного за выполнение заявки. Может оставить комментарий.

После выполнения заявки, в группе для заявок сотрудник отмечает статус выполнения заявки.

Бот отправляет пользователю информацию о том что его заявка выполнена
